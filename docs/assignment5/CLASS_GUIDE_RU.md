# Новые и изменённые классы

Полный список ответственности всех исходных классов находится в README. Здесь разобраны изменения Assignment 5.

## Расчёт стоимости parking.pricing

- **PricingStrategy** — интерфейс с одним методом amountFor(hours). Любая стратегия стоимости обязана вернуть сумму.
- **HourlyPricing.amountFor** — проверяет часы, умножает на 500.
- **CappedPricing.amountFor** — считает обычную цену, ограничивает её 3000 KZT.
- **DemandPricing** — получает OccupancySource в конструкторе. amountFor читает загрузку, проверяет диапазон, добавляет доплату только после первых двух часов. При 8 часах и загрузке 0.8: 4000 + 200 × 6 = 5200.
- **DurationRules.requireValid** — допускает от 1 до 24 часов; иначе бросает ParkingException.
- **OccupancySource.occupancy** — собственный контракт для внешнего значения загрузки.
- **SimulatedOccupancySource** — хранит показание. setOccupancy проверяет новое значение; occupancy возвращает текущее.
- **PricingSituation** — record с длительностью и местным часом; проверяет их при создании.
- **PricingSelector.manual** — создаёт конкретную стратегию по имени. setMode сохраняет ручной режим или auto. select в auto применяет правила по порядку: длинный визит, ночь, высокая загрузка, обычный тариф. mode возвращает имя текущего режима.

## Существующий контекст PricingPolicy

Конструктор без аргументов сохраняет прежний hourly тариф. Основной конструктор принимает PricingStrategy. setStrategy заменяет ссылку; amountFor вызывает strategy.amountFor(hours). Условий по типу стратегии здесь нет. Конструктор с именем режима оставлен для одинаковых тестов до и после; выбор он передаёт отдельному селектору.

## Выбор места parking.allocation

- **AllocationStrategy.choose** — интерфейс выбора номера места по SpaceAvailability.
- **SpaceAvailability** — неизменяемый record: свободные места и число прошлых использований. from исключает занятые и заблокированные места; при отключённых датчиках или полном гараже сохраняет старые ошибки.
- **FirstFreeAllocation.choose** — возвращает наименьший номер свободного места.
- **NearLiftAllocation.choose** — выбирает ближайшее место к лифту возле места 2. При равном расстоянии берёт меньший номер.
- **LeastUsedAllocation.choose** — выбирает место с минимальной историей бронирований. При равенстве берёт меньший номер. Отсутствующая история означает ноль.
- **AllocationSituation** — хранит предпочтение лифта и местный час.
- **AllocationSelector** — manual создаёт стратегию по имени; setMode задаёт режим; select выбирает lift при предпочтении лифта, balanced днём, first в остальных случаях. Ручной режим имеет приоритет.

## Существующий контекст SpaceSensorGrid

Старый конструктор и firstFree сохранены. Основной конструктор принимает AllocationStrategy. setStrategy заменяет алгоритм; choose делегирует выбор; перегрузки firstFree создают входной снимок. Сам контекст не выбирает реализацию по типу.

## Изменения существующих подсистем

**ReservationManager.reserve** по-прежнему сначала проверяет старую бронь по ID. Если она существует, не выбирает другое место. Для новой брони собирает занятые места и историю всех сохранённых броней, передаёт их SpaceSensorGrid. release, find, all и управление датчиками работают как раньше.

**PriceQuote** — record с id операции, длительностью и первым рассчитанным amount.

**BillingRepository.findQuote/saveQuote** — читают и сохраняют price_quotes.csv. Старые методы оплат и формат billing.csv сохранены.

**PaymentTerminal.confirm** проверяет часы, читает или создаёт quote, проверяет совпадение длительности, затем выполняет старую логику оплаты. Смена стратегии не меняет сохранённый quote. Старые записи Assignment 4 без quote проверяются как hourly. reverse, find, all и overdueIds сохранены.

## Запуск и демонстрация

**GarageApplication** собирает старые подсистемы вместе с контекстами и селекторами. configureStrategies валидирует выбранные режимы и датчик перед изменением конфигурации. prepareStrategies(hours) выбирает реализации по текущему запросу и времени Asia/Almaty, затем вызывает setStrategy у контекстов. strategyModes возвращает выбранные режимы. Программный клиент должен вызвать prepareStrategies перед новым park/begin, как это делает Main.

**Main** сохраняет пункты 1–12. Пункт 13 вызывает StrategyDemo; 14 задаёт конфигурацию. Перед новым begin передаёт реальные часы в prepareStrategies. Обрабатывает ошибочные имена режимов и неверное показание датчика.

**StrategyDemo** не пишет в рабочую базу. run показывает три цены и три разных места для одинакового входа, автоматические правила, ручное переопределение и смену стратегии у того же объекта. main позволяет запустить демонстрацию отдельно.

## Тесты

**PricingContractTest** не меняется между коммитами: 16 запусков проверяют результаты трёх тарифов, допустимые границы, положительность, изменение внешнего показания и старый тариф по умолчанию.

**StrategyTest** напрямую тестирует все шесть алгоритмов, каждое правило селектора, границы времени и загрузки, ручной выбор, внешние данные, setStrategy, собственные реализации без регистрации, историю мест, обе компенсации Facade и восстановление цены после сбоя.

Оригинальные SubsystemTest, WorkflowTest, CompensationRecoveryTest, StoreTest и ParkingScenario сохранены без правок.
